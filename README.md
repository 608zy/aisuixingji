# AI 随行记

基于 **Vue 3 / uni-app + uniCloud** 的旅行游记应用，覆盖客户端页面、Node.js 云函数、云数据库和管理页面，作为个人跨端应用开发实践。

## 功能

- 游记生成与编辑：接入兼容 OpenAI 协议的大模型接口，处理文本、图片输入。
- 旅行内容管理：本地保存游记、云端同步、社区互动与地图展示。
- 跨端调试：使用 HBuilderX 运行微信小程序及 Android 应用。
- 管理页面：使用独立 Web 页面访问管理员云函数，部署时应限制访问。

## 技术结构

```text
uni-app 页面
  ├─ 本地存储与状态处理
  └─ uniCloud 云函数（Node.js）
       ├─ 登录态校验与业务处理
       ├─ 云数据库读写
       └─ 模型 / 地图服务调用
```

Node.js 开发实践主要在云函数环境中，不是独立 Express 或 NestJS 服务。

## 实现要点

- 同步云函数校验 uni-id 登录态，使用服务端确认的用户 ID 处理数据。
- 通过用户 ID 和本地记录 ID 查询已有游记，跳过已同步记录；该机制不等于严格的并发幂等保证。
- 云函数校验模型请求参数并返回错误状态，客户端处理生成与保存流程。
- 使用本地存储保留游记，再按登录和网络情况同步云端。

## 运行

1. 使用 HBuilderX 打开项目根目录。
2. 关联自己的 uniCloud 阿里云空间。发布副本不包含个人云空间绑定凭据，需按 HBuilderX 提示重新关联。
3. 上传项目需要的数据库结构、索引和云函数；启用登录功能时配置 uni-id 相关模块。
4. 按项目设置页面填写自己的模型服务配置。云端 `ai-plan` 使用 `AI_API_KEY`、`AI_API_BASE_URL`、`AI_MODEL` 环境变量；`get-weather` 使用 `BAIDU_MAP_AK`。
5. 配置地图服务和小程序合法域名，在 HBuilderX 运行到微信开发者工具，或配置 Android 真机运行。

云服务、模型服务和地图服务需要自行开通配置。请勿将真实密钥写入公开源码。

### 基础检查

```bash
npm install
npm test
```

检查工具函数和 Vue 文件。它不覆盖云函数部署、模型响应或 Android 真机行为；这些需要配置自己的服务后单独验证。
